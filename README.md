# 🏎️ Formula 1 2D Racing

A top-down, bird's-eye browser 2D Formula 1 racing game with authentic vehicle physics, iconic circuit layouts, telemetry dashboard, Web Audio API sound synthesis, DRS, and ERS hybrid boost.

## 🎮 Controls

| Action | Primary Key | Secondary Key | Touch / UI |
|---|---|---|---|
| **Accelerate** | `Arrow Up` | `W` | On-screen `▲` |
| **Brake / Reverse** | `Arrow Down` | `S` | On-screen `▼` |
| **Steer Left** | `Arrow Left` | `A` | On-screen `◀` |
| **Steer Right** | `Arrow Right` | `D` | On-screen `▶` |
| **DRS Wing Flap** | `F` | `Shift` | `DRS` button / Press `F` |
| **ERS Overtake Boost** | `Space` | `E` | On-screen `⚡` |
| **Camera Mode** | `C` | - | `🎥 CHASE CAM` button |
| **Reset Car to Grid** | `R` | - | `🔄 RESET` button |
| **Lap Times Table** | `T` | - | `⏱️ LAP TIMES` button / Timing Card |
| **Audio Volume / Mute** | `M` | - | Volume Slider (0-100%) / Speaker icon |
